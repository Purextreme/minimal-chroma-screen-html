# Minimal Chroma Screen HTML

一个免安装、离线可用的极简蓝幕 / 绿幕页面，适合摄影师拍摄电脑屏幕时避免桌面、任务栏、壁纸和其它 UI 干扰。

## 在线使用

访问 [Minimal Chroma Screen](https://purextreme.github.io/minimal-chroma-screen-html/)，操作方式与离线版相同。

## 使用方法

1. 双击打开 `标记绿幕.html`
2. 按 `F11` 进入浏览器全屏
3. 点击页面切换蓝色 / 绿色背景
4. 按 `Space` 循环切换 5 个 / 9 个 / 25 个 / 49 个十字 / 黑白棋盘格 / 隐藏
5. 按 `L` 锁定 / 解锁操作，避免误触

## 特点

- 单 HTML 文件
- 无 npm
- 无框架
- 无 CDN
- 无后端
- 可离线使用

## 部署

推送到 `main` 分支后，GitHub Actions 会自动将 `标记绿幕.html` 作为网站的 `index.html` 发布到 GitHub Pages。只需维护原 HTML 文件，无需另外同步网页副本。
